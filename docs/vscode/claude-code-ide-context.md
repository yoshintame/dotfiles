# Claude Code VSCode: авто-инъекция IDE-контекста

## TL;DR

Нативное расширение Claude Code для VSCode на каждом сообщении пользователя автоматически добавляет в контекст модели путь активного файла и содержимое выделения. **Настройки, чтобы это отключить, не существует** — только `claudeCode.selectedModel` и `claudeCode.preferredLocation`. Есть обходные пути через snимание выделения и закрытие вкладок.

---

## Поведение

Расширение подмешивает к каждому user-сообщению один из двух тегов в зависимости от состояния редактора:

| Состояние редактора | Тег | Что попадает в контекст |
|---|---|---|
| Файл открыт, ничего не выделено | `ide_opened_file` | Только абсолютный путь файла |
| Файл открыт, есть selection | `ide_selection` | Путь + диапазон строк + содержимое выделенного блока |
| Ни одной вкладки не открыто | — | Ничего не добавляется |

Содержимое активного файла целиком **не** передаётся — только путь. Полный текст уходит лишь если пользователь явно прикрепил файл через `@filename` или если модель прочитала его через `Read`.

### Пример `ide_opened_file`

```
The user opened the file /Users/.../theme.ron in the IDE.
This may or may not be related to the current task.
```

### Пример `ide_selection`

```
The user selected the lines 15 to 24 from /Users/.../curl-to-webfetch.sh:
<содержимое строк 15–24>
This may or may not be related to the current task.
```

Проверено экспериментально 2026-04-22 в активной сессии.

---

## Проблема

Теги подмешиваются автоматически и «засоряют» контекст сессии данными, которые часто не имеют отношения к задаче. Пример: обсуждаешь архитектурный вопрос в чате Claude, а в редакторе открыт посторонний конфиг — его путь уходит в контекст и модель может отвлечься на него.

Официального флага `settings.json` для отключения этого поведения **нет**. Документация Claude Code подтверждает: единственная управляемая часть — видимость selection через иконку-глаз в футере поля ввода.

---

## Обходные пути

1. **Снять выделение** перед отправкой сообщения — уберёт `ide_selection`, останется только `ide_opened_file` с путём.
2. **Иконка-глаз (eye-slash)** в футере поля ввода Claude — скрывает selection из следующего turn, не снимая выделение в редакторе.
3. **Закрыть все вкладки** — `Cmd+K Cmd+W`. Тогда и `ide_opened_file` не будет.
4. **Работать в sidebar** без активного редактора — открыть панель Claude, свернуть редактор.
5. **`/context`** — показывает, что реально лежит в окне контекста в данный момент. Полезно для самоконтроля.

## Связанные настройки

- [modules/vscode/config/settings.json](../../modules/vscode/config/settings.json) — `claudeCode.selectedModel`, `claudeCode.preferredLocation` (единственные опции расширения).

## Если появится флаг

Актуальные настройки расширения можно смотреть в VSCode: `Cmd+,` → поиск `claudeCode`. Если в будущих версиях появится опция вида `claudeCode.disableIdeContext` или аналог — обновить этот документ и добавить её в `settings.json`.
