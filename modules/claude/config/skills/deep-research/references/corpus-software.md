# Корпус: софт

Для OSS-дискавери три источника — три разных ключа над одним множеством репозиториев, и у двух из трёх сломан retrieval:

| Источник | Индексируется по | Отказ |
|---|---|---|
| GitHub | авторские `name`/`description` — словарь того, кто инструмент уже знает | циркулярно: чтобы найти, надо знать слова автора. Замер: 0–1 попадание на 3–4 разумных запроса |
| Reddit / HN | **анонс** — автор объясняет инструмент чужим, то есть словарь ищущего | ранжирование Reddit антикоррелирует (ниже); HN в порядке |

Выкинуть любой из трёх — дыра. Кураторские индексы (awesome-списки) бьют все три — майнить первыми.

## Reddit: сортировка решает

- **Дискавери → `--sort new`.** Анонсы живут на 0–12 баллах; `relevance` и `top` скор-взвешены и ранжируют против них. Замер на r/ClaudeCode: `--sort top --time year` + "search" → 20 результатов, ноль инструментов; `--sort new` + "built" → семь анонсов из 20. Сканируй заголовки, скором не фильтруй.
- **Настроения и migration stories → `relevance` или `top`** — там высокий скор и есть сигнал.

```bash
search-reddit search "built" --sub <subreddit> --sort new --time year --limit 25
```

## HN

Ценность HN — не аудитория и не комментарии, а работающий поиск Algolia по заголовкам и текстам анонсов. Для OSS-дискавери запускай, даже когда тема кажется не-HN-ной; вне OSS отдача не доказана — по умолчанию не тянись.

```bash
search-hn search "<query>" --tags show_hn
```

## Awesome-майнинг — три шага

```bash
search-github awesome "<capability>"     # ракурс 1: возможность
search-github awesome "<ecosystem>"      # ракурс 2: экосистема
gh api repos/<owner>/<repo>/contents/README.md --jq .content | base64 -d | rg -i '<keywords>'
search-github search "<query>"           # добивка: ≥3 формулировки имени
```

Найти awesome-список — не значит прочитать его: окупается греп README, а не результат поиска. Список, найденный шагом 1 и не грепнутый, — несделанный шаг.

`search-github search` буквален по `name`/`description` — попадает, только когда запрос почти цитирует автора; главным каналом дискавери быть не может. Звёздные фильтры (`--stars ">30"`) молча режут хвост, где живут новые инструменты, — во время дискавери не ставь.

## Красные флаги кандидата

Заброшенность, смена лицензии, единственный мейнтейнер, отставание релизов от кода, рост цены, треды «ушли с него на …».
