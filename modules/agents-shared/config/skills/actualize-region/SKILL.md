## Дельта поверх /extract

`actualize-region` — стадия 2 (содержимое) reconcile-пайплайна из трёх сессий: `/state-reconstruction` (стадия 1) поднял незафиксированное, `/reconcile` (стадия 3) переложит регион под инвариантом доверия «содержимое правильно и актуально, раскладка кривая» — твой выход обязан сделать это утверждение верным. Догнать одну спеку по ходу — `/actualize-spec`. Применяй весь пайплайн и гарды `/extract`; ниже — только дельта.

1. **Вход.** Handoff с quiesce-дистиллятом стадии 1 («Незакрытое», «Факты только в сессиях»). Без него — начни пайплайн со `/state-reconstruction`: актуализация по неполной картине закрепляет устаревшее.
2. **Прочитай регион целиком**; границу держи по связям, не по папке.
3. **Чини по месту.** Аудит `/extract` («найди и проверь связанное», шаг 3) — по региону целиком: ошибки, внутренние противоречия (реши, в чью пользу, и выправь все стороны), устаревшее и расхождения с реальностью (код / конфиг / git), битые ссылки. Quiesce-факты вливай в их доки-дома.
4. **Структурные ходы запрещены.** Не переноси, не переименовывай, не меняй `type:`, не расщепляй и не сливай доки — раскладка принадлежит стадии 3. Гард 4 применяй только внутри файла (переписать начисто на месте); его ветку «разбей на доки» здесь не исполняй — пометь кандидата в дистилляте.
5. **Финал стадии.** Обычный финал `/extract` (проверка, FM1-линтер, коммит шагами). Затем `/handoff-create` стадии 3; в теле — дистиллят для инварианта доверия: какие ошибки сняты, какие противоречия в чью пользу решены (стадия 3 не должна регенерировать выправленное при rewrite), кандидаты на расщепление из шага 4, диапазон коммитов стадии — детали ссылкой на коммиты, не пересказом.
