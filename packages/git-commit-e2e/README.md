# git-commit e2e

Автотесты для `git commit-context` и `git commit-edit`.

Запуск:

```bash
bun test /Users/yoshintame/.dotfiles/packages/git-commit-e2e
```

или:

```bash
bun test /Users/yoshintame/.dotfiles/packages/git-commit-e2e/git-commit.e2e.test.ts
```

Проверка типов:

```bash
bun run typecheck
```
