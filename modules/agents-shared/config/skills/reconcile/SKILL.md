## Дельта поверх /extract

`reconcile`: **прочитай всё, что зафиксировано** по региону → **актуализируй это знание** (исправь ошибки, противоречия, устаревшее) → **сними старую фиксацию** → **выполни `/extract`** над полученным знанием как над незафиксированным выводом сессии. Догнать одну спеку по ходу — `/actualize-spec`; reconcile — разовый, на целый деградировавший регион. Применяй весь пайплайн и гарды `/extract`; ниже — только дельта.

1. **Quiesce-preflight (реконструкция состояния).** Подними незафиксированный контекст брошенных сессий **до** аудита, иначе будешь актуализировать по неполной картине: прогони `/state-reconstruction` по региону — его «Незакрытое» и «Факты только в сессиях» и есть вход аудита.
2. **Широкий обзор.** Аудит `/extract` («найди и проверь связанное», шаг 3) прогони по региону целиком; границу держи по связям, не по папке. Сверх его корректностного чеклиста ищи **структурную** деградацию, которой в обычном extract нет: конфляция ролей (один док = несколько ролей), отсутствующие типы (сущность погребена в теле другого дока), брошенный WIP, рваность от точечных правок, разбухание (**>500 строк**).
3. **План реструктуризации** — одним сообщением, два обязательных блока; дождись подтверждения перед перетряской:
   - **(а) Целевая раскладка** — дерево файлов/папок по типам и ролям, спроектированное так, как если бы знания региона **нигде не были зафиксированы** и раскладывались с нуля.
   - **(б) Вердикт каждому старому файлу**: `удалить` / `остаётся домом` / `переехать в <путь>`. Файлов региона без вердикта в плане нет.
4. **Структурные ходы — исполнение плана.** Целевые доки пиши с нуля чистыми снимками (старые — источник фактов, не черновик); уникальный unit сначала приземли в целевой дом, затем источник **удали** по вердикту — git хранит всё, а страх сноса старого — главный режим отказа reconcile. Расщепление свалки, ретипизация, выпуск погребённых сущностей (Гард 3), переписывание начисто (Гард 4) — частные случаи метода; бэклинки удалённых — де-линкуй или перенацель.
5. **Сверка с планом + актуализация.** Пройди план шага 3 построчно: каждый вердикт исполнен буквально, каждый целевой док существует и несёт своё знание; отклонение — либо явно обоснуй, либо доделай. Затем обычный прогон `/extract` по каждому затронутому current-state доку (догнать под реальность, FM1-линтер, коммит). Коммить шагами, не одним комом.
