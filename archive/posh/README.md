# posh (archived)

Нативный Windows PowerShell-профиль: `yoshintame.settings.ps1` (PSReadLine, PSFzf, starship, zoxide, eza-алиасы) + `packages.ps1`. Рабочий конфиг с игрового ПК до Nix-эпохи, оставлен для референса и шаринга.

**Не вписан ни в один хост.** Отставлен решением `windows-shell-in-wsl-only` (vault) — интерактивный shell на Windows-хостах теперь только fish внутри WSL (NixOS-WSL), нативного PowerShell-слоя нет.
