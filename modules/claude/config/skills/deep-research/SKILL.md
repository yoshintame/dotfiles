# Deep Research

## Веб, не память

Каждое содержательное утверждение отчёта берётся из найденного в вебе — обязательно используй WebSearch и WebFetch, не отвечай из обучающих данных. Без этого правила агент с полным доступом к вебу пишет research-ответ из памяти: замер на четырёх реальных кейсах — три прошли с нулём веб-запросов, включая апелляцию к «международному консенсусу» по ветеринарному протоколу без единой ссылки. Знание из памяти годится только как гипотеза для формулировки запроса.

WebSearch — первичный источник: ранжирование Google достаёт кураторский экспертный контент (документацию, обзоры, блоги) плотнее, чем Reddit или HN. Скрипты сообществ — дополнительный слой, не старт.

## Выход до пайплайна

Однострочный фактический вопрос («что такое X») — не deep research: ответь одним WebSearch, скажи, что пайплайн не понадобился, ноту не пиши.

## Бриф и роутер

Переписывая реплику пользователя в исследовательский бриф, помечай инференс: ограничение, которого пользователь не давал (версия, бюджет, конкретные репозитории), называется вслух как допущение, а не подаётся дальше как требование.

Два вопроса роутера:

1. **Что на выходе?**
   - ранжированный шортлист с рекомендацией → читай `references/choice.md`;
   - консенсус с оценкой силы доказательств → читай `references/evidence.md`;
   - объяснение механизма, наличие багрепорта или обхода → профильного файла нет, дальше по хребту.
2. **Что приобретается?** — только при «шортлист»:
   - софт → `references/corpus-software.md`;
   - товар или услуга → `references/corpus-market.md`.

Составной запрос («когда стерилизовать и где в Бангкоке») подгружает все подходящие профили, не один из них.

## Поиск

Начинай с WebSearch: именная группа темы, год при чувствительности к свежести (текущий — из `# currentDate` системного контекста), уточнитель — локация, язык, аудитория. 2–4 итерации, прежде чем тянуться к скриптам.

Скрипты — когда у темы есть измерение локального знания, живого опыта сообществ или OSS. Все на `$PATH`, поддерживают `--help` и `--json`:

- **Reddit** — опыт сообществ, локальное знание, анонсы: `search-reddit search "<query>" --sub <sub> --limit 20`; запросы держи в 2 слова, длиннее — только с `--sub`. Тред целиком — `search-reddit fetch <url>`, не WebFetch: вывод чище;
- **HN** — единственный из трёх с работающим полнотекстовым поиском: `search-hn search "<query>" --min-points 30`; тред — `search-hn fetch <id>`;
- **GitHub** — awesome-списки, здоровье репо: `search-github`, **каждый вызов — с `dangerouslyDisableSandbox: true`**: под сандбоксом он умирает с `tls: failed to verify certificate: x509: OSStatus -26276`, а ошибка читается как обычный сбой команды.

Тактики OSS-дискавери — сортировки Reddit, awesome-майнинг, ключи индексации трёх источников — в `references/corpus-software.md`.

## Гигиена запросов

Пустой результат — факт о твоём запросе, не о мире. Свидетельством отсутствия он становится только после того, как исключён сам запрос.

- **Упавший вызов — не результат.** Ненулевой exit, `gh error:`, TLS-ошибка, `IncompleteRead` → перезапусти; с `dangerouslyDisableSandbox: true`, если замешан сандбокс. Упавший вызов не засчитывается в покрытие.
- **Пустая выдача отфильтрованного или длинного запроса — не доказательство отсутствия.** Перезапусти короче и без фильтров, прежде чем заключать.
- **Один негативный ответ не закрывает шаг.** `awesome "<capability>"` вернул пусто → пробуй `awesome "<ecosystem>"`, а не вычёркивай awesome-списки целиком.
- **Имя, взятое из анонса, резолвится через `fetch` самого анонса.** URL репозитория почти всегда в теле поста: `search-reddit fetch <url>` / `search-hn fetch <id>` сначала, `search-github search` потом. Пустой GitHub-поиск по имени из анонса не доказывает ничего.

## Синтез

Противоречия источников сталкивай явно, не сглаживай. Утверждение с единственным источником помечай как одиночное.

## Нота в vault

Каждый прогон заканчивается сохранением отчёта нотой `type: deep-research` в Obsidian vault пользователя — не спрашивая. Пропуск — только для выхода до пайплайна.

Конвенции vault — в скиле `obsidian-vault`: размещение, именование, схема frontmatter (`_types/deep-research.type`), связи только во frontmatter. Поверх них:

- `status: current`, `date` — сегодня из `# currentDate`;
- слаг: добавь `-<год>`, если тема чувствительна к свежести;
- тело — синтез; секция `## Источники` со внешними URL обязательна;
- 1–3 реальных ссылки в `linked:`; если напрашивается хаб области — впиши ноту и туда.

После записи покажи отчёт в чате с кликабельным путём ноты.
