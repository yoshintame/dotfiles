`reconcile` = `/extract` + разовый аудит и реструктуризация целого региона в плохом структурном состоянии. Применяй весь пайплан и гарды `/extract` (роутинг, FM1-линтер, пропорция/альтитуда, одна-роль, переписать-начисто) — ниже только дельта, гарды не повторяю. Широкий и разовый: берёшь регион (конфляция ролей, отсутствующие типы, погребённые сущности, брошенный WIP) и приводишь к модели; догнать одну спеку по ходу — это `/actualize-spec`.

Чинит в первую очередь **конфляцию ролей** — наследие до-правиловой эпохи, когда док копил что/почему/план/историю, пока не стал «не пойми чем». Это lifetime-накопление, поэтому разовая чистка, а не вечный линтер.

## Дельта поверх /extract

1. **Quiesce-preflight (реконструкция состояния).** Подними незафиксированный контекст брошенных сессий **до** аудита, иначе будешь актуализировать по неполной картине: `/find-session` по региону + git (недавние коммиты, `git stash list`, `git diff`, uncommitted-правки). Что не легло в артефакты — собери здесь.
2. **Широкий обзор.** Аудит `/extract` (найди-и-проверь связанное — противоречия, ошибки, устаревшее, расхождение с реальностью, битые ссылки, пробелы) прогони по региону целиком; границу держи по связям, не по папке. Сверх его корректностного чеклиста ищи **структурную** деградацию, которой в обычном extract нет: конфляция ролей (один док = несколько ролей), отсутствующие типы (сущность погребена в теле другого дока), брошенный WIP, рваность от точечных правок, разбухание (**>500 строк**).
3. **План реструктуризации** — одним сообщением: какие структурные ходы, по каким докам. Дождись подтверждения перед массовой перетряской.
4. **Структурные ходы** (то, чего нет в обычном `/extract`):
   - **расщепить свалку** на отдельные типизированные доки по ролям (Гард 3): погребённую сущность выпусти в свой типовой инстанс;
   - **ретипизация** — сменить `type:` под истинную роль дока;
   - **перенос** — папка/`parent:` под новый тип;
   - **переписать начисто** деградировавшие доки (Гард 4).
5. **Актуализация.** После структурных ходов — обычный прогон `/extract` по каждому затронутому current-state доку (догнать под реальность, FM1-линтер, коммит). Коммить шагами, не одним комом.
