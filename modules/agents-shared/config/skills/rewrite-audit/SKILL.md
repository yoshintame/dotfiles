---
name: rewrite-audit
description: Независимая проверка /rewrite на потерю информации.
---

Вход — handoff от `/rewrite`: база (коммит до перекладки), диапазон, карта «старый файл → новые дома», список осознанных удалений. Предмет — сохранность знания, не раскладка: где что лежит, решено; спорить можно только о потерянном содержании. Содержание перед перекладкой прогнано `/actualize`, так что «устарело» ≠ «потеряно» — факты не дочинивать, расхождение с реальностью фиксировать пунктом отчёта.

1. **Разложить диапазон.** `bun ~/.claude/skills/rewrite-audit/scripts/audit-map.ts <repo> <base> <head> [pathspec…]` печатает таблицу переездов, удалений и добавлений с similarity. Переезд с телом без изменений (`R100`) сверять не нужно — только frontmatter; переезд с правками и удалённые файлы — по карте handoff'а; добавленные — это дома. Оригинал любого файла: `git -C <repo> show <base>:<path>`.
2. **Units, не абзацы.** По каждому старому файлу выписать units — факт, число, команда, оговорка, отвергнутая альтернатива с причиной, открытый пункт, ссылка — и найти каждый в новых домах. Файлы, переписанные начисто (hub'ы, свалки ролей), — по одному субагенту на файл: только чтение, вход — старый текст и пути домов, выход — список ненайденных units. Правки делает основная сессия, иначе агенты потянут одни и те же доки.
3. **Что не потеря.** Аудит держит те же гарды, что и перекладка, иначе он тащит срезанное обратно:
   - разворотный язык и хроника в current-state доке (Гард 1);
   - пересказ кода в implementation-spec — списки файлов и папок, инвентарь команд, раскладка директорий модуля (Гард 5): протухнет на первой правке репо;
   - резолвленные open-questions и defer-крошки без собственного вопроса;
   - вводные-клей и дубли между hub'ом и спекой;
   - всё из списка осознанных удалений handoff'а.
   Спорный unit — в отчёт, не в файл.
4. **Куда возвращать.** Потерянный unit едет в дом по роли, не в hub: rationale и user input — в decision или frozen analysis, не в спеку; открытый пункт — в open-question; рецепт — в knowledge. Оговорки оригинала («если есть», «не проверено») либо проверяются, либо сохраняются — в факт не превращать.
5. **Ссылки по смыслу.** Перекладка нацеливает бэклинки удалённых файлов механически (всё → hub). Каждый такой линк — на точную цель: пункт backlog'а → его open-question или decision, community-evidence → deep-research. `[[area]]` там, где имелся проект или его фазы, → проект.
6. **Чужой WIP.** Файл, грязный до аудита, коммитить только своим ханком: `git-commit-atomic -C <repo> --auto "<msg>" <файлы> -- <patch>`; позиционный файл стейджится целиком и уносит чужие правки под твоё сообщение.
7. **Отчёт** — по каждому файлу карты: `полностью` / `потеряно: <units> → <куда возвращено>` / `осознанно снято`. Спорные units — отдельным списком на решение владельца.
